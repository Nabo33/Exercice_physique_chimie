📖 Mesurer le volume d’un solide

Pour connaître le volume d’un solide qui rentre dans une éprouvette graduée, on peut le plonger dans l’eau. Le niveau de l’eau monte : cette augmentation correspond au volume du solide.

1 Je mesure le volume d'eau présent au départ dans l'éprouvette graduée.
Vinitial
2 J’ajoute doucement le solide dans l’éprouvette graduée.
Le niveau de l'eau augmente.
3 Je mesure de nouveau le volume présent dans l'éprouvette graudée : c'est le volume final
Vfinal
🧮 Expression littérale :
Vsolide = Vfinal − Vinitial
Exemple :
Vinitial = 24,0 mL et Vfinal = 26,0 mL
Vsolide = Vfinal − Vinitial
= 26,0 − 24,0
= 2,0 mL
💪 Le solide a donc un volume de 2,0 mL.
